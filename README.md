# Food Delivery Web Application

A full-stack food delivery web application built using Python, Flask, and Flask-SQLAlchemy.

## Features
- User Registration, Login, and Logout (Flask-Login)
- Restaurant and dynamic menu listings
- Persistent shopping cart and order management
- Order history tracking
- Automated database seeding

## Setup Instructions
1. Place `app.py`, `models.py`, `routes.py`, and the `templates/` folder inside your project root directory.
2. Install dependencies: `pip install flask flask-sqlalchemy flask-login`
3. Run the application: `python app.py`
4. Access via browser at `http://127.0.0.1:5001`
